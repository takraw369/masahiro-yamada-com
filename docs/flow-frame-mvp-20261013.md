# FLOW FRAME MVP

Purpose: Turn one locally selected screenshot into five ready-to-share images from the existing authenticated MASA Dashboard.

Included: file or clipboard image input, editable Japanese copy, brand and palette controls, live canvas preview, PNG export, and five-file ZIP export.

Sizes: Instagram 1080×1350, square 1080×1080, story 1080×1920, note 1280×670, sample 6.9-inch App Store 1320×2868.

Images are processed in the browser and not uploaded. URLs are metadata fields, not automated page captures. AI writing, publishing and FLOW COMPASS are future extensions; none are claimed as implemented.

Manual QA: test five output dimensions and ZIP validity, large images, card/phone framing, text length, mobile responsiveness (375/390/430 px), login and navigation, and local-only processing. Current branch remains behind PR review and separate deploy gate.
