# 乙4 鑑別・写真教材 受け取りと照合台帳
更新：2026-10-09　ステータス：**教材p293〜309の写真受領・照合待ち**

## 用途
この台帳を今後送付される教材写真の照合台帳として再利用。**古いアプリDBの78項目は「掲載あり」の証明にならない。**
原本のページ画像、正式名称、用途、形状が照合できたものだけ「教材掲載確認」に昇格する。掲載ページを推測で埋めない。既存の外部写真は教材写真と取り違えない。

## 固定条件
- 「写真がないのに名称・用途を答えさせる」画面は不可。画像の取得完了まで設問・採点・裏面を表示しない。外部写真の取得失敗は自動スキップ。
- 公式教材でない画像を**確認済み／完全網羅**と表記しない。新たな教材写真は出典・利用許諾に沿って扱う。
- 本番鑑別から除外するように既に指定された炎感知器・赤外線式などと、旧記述テスト除外4件は**明示確認がない限り復活させない**。歴史データは消去しない。
- 後ろのページを多めに、△・×および忘却（日数）を強く優先。既存の保存キーを変えない。
- 画像を受け取ったら「ページ→器具→器具名/用途→写真番号→学習/テスト適否」順で記録。

- 現時点でこの会話で確実に確認できるユーザー画像：**公開アプリのエラースクリーンショット1点**。教材p293〜309の原本画像はここからは未確認。

- 旧写真DB：78項目。画像参照のないものが50項目（2026-10-09確認時点）。参照がある28項目も教材一致は未確認。
- PR #278（未マージ）は画像の根拠が不十分なため正本に採用しない。今後の写真の追加は本台帳を更新して行う。
