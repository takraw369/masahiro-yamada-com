## 正本と保存範囲

- 問題・解説の正本：GitHub `public/otsu4/questions.js`（48問、四択41＋記述7）。新規一覧には問題文を転記しない。
- 項目分類の実装：`public/otsu4/tests/core.js`。分類と問題IDの対応のみを保持。
- 項目別回答は既存 `otsu4-study-state-v1` に追記。誤答・正解でも△は総合演習の弱点選択で使われる。
- 既存 `otsu4-study-session-v1` は変更しない。途中の項目別テストだけ `otsu4-topic-test-session-v1` で保持する。
- 工具鑑別・基礎レッスン・別表専用の記録は別。すべてのアプリの進捗を自動統合したとは扱わない。
- 保存は同じ端末・同じブラウザ内。乙6履歴には書き込まない。サーバー同期や新DB追加は今回の範囲外。

## 重複回避・後続AIへの引継ぎ

1. 新しいテスト作成前に、この一覧・公開URL・最新master・関連PRを再確認する。保存時点の状態だけで判断しない。
2. PR #240でマージ済みの法令／別表第1ページを正本ルートとして扱う。別の同名ページ・別表データを作らない。自火報の用途／面積／例外の入念な問題化は同トラックで整備する。
3. PR #218は既存 `public/otsu4/app.js` の関連論点表示。今回そのファイル・スタイル・既存ホームを変更しない。
4. 鑑別は既存 `/otsu4/kambetsu/` を正本として使う。画像・名称／用途・○△×・講習順の段階解放を別実装しない。新規項目は重複を確認して同じ配列と講習順へ統合する。
5. 新問が必要なら、一次資料の根拠と適用条件を確認して既存問題DBへ追加する。専用法令データの担当とは照合する。
6. 一覧の「実装済み」と「本番公開済み」を分ける。マージ・CI・公開HTTPの確認後にのみ公開状態を更新する。

## 未収録・要拡充

別表全項、特定／非特定の詳細、自火報設置の用途別面積と例外は、今回の既存48問の集中テストで網羅できない。PR #240で専用導線と別表ドリルはマージ済み。設置基準の問題群は引き続き拡充対象。P型1級／2級、火災通報装置、感度試験器・減光フィルター、発信機などは2026-10-07の鑑別データへ追加したが、これは「画像から名称・用途を取り出す」範囲の収録であり、筆記／記述問題DBまで網羅した意味ではない。電気のリアクタンス・変圧比等も引き続き拡充対象。

## 鑑別の出題優先（2026-10-06追記）

`/otsu4/kambetsu/` は2026-10-07から、講習で渡された順を正本の学習順として扱う。74項目を最初から一括表示せず、初回は先頭6項目だけを解放し、4項目が安定した○になるごとに後続3項目を追加する。通常は講習順を保ちつつ、過去と当日の ×（自動不正解を含む）を最優先、△を次点として順序へ割り込ませる。×・△は同一セッション中にも数問後に再出題し、直後の丸暗記ではなく再想起を確認する。ロック中の名称は弱点一覧にも表示しない。
