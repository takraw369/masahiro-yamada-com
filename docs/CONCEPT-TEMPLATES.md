# CONCEPT TEMPLATES

Purpose: start design work from a concept-specific default instead of a blank canvas.

## Template format

```md
# [Concept Name]
- Audience:
- Primary purpose:
- Core feeling:
- Visual direction:
- Layout grammar:
- CTA strategy:
- Button direction:
- Card direction:
- Motion direction:
- Ideal section order:
- Must avoid:
- Good component candidates:
```

## 1. ACE METHOD — flagship authority / transformation

- **Audience:** athletes, parents, growth-oriented adults
- **Purpose:** trust, transformation, inquiry, participation, deeper study
- **Core feeling:** disciplined, deep, earned, high-trust
- **Visual:** quiet luxury, black + gold, editorial spacing, sharp geometry
- **Layout:** hero -> problem reframing -> method/mechanism -> who it is for -> offer/pathway -> CTA
- **CTA:** one primary action per section
- **Buttons:** square primary, outline secondary, decisive rather than playful
- **Cards:** sharp edges, clean borders, low decoration
- **Motion:** restrained reveal, text emphasis, scroll pacing
- **Avoid:** hype marketing, fake urgency, colorful clutter, generic AI-LP styling
- **Candidates:** Text Reveal, Spotlight, Arrow Fill Button, Scroll Stack

## 2. SLF BOOK CAFE — warm exploration / gift / bookshelf

- **Audience:** community members, learners, LINE registrants, families
- **Purpose:** discovery, delight, content browsing, opt-in or purchase
- **Core feeling:** warm, curious, slightly magical, welcoming
- **Visual:** library/cafe/shelf metaphor, tactile, human, playful but elegant
- **Layout:** welcome -> featured shelf -> preview/excerpt -> category browsing -> buy/LINE/gift path
- **CTA:** discovery first, conversion second
- **Buttons:** slightly softer than ACE; mild radius is allowed when it supports warmth
- **Cards:** books, shelves, gift modules, preview drawers
- **Motion:** book pull-out, light parallax, reveal, restrained gift-opening celebration
- **Avoid:** cold SaaS grids, financial-looking UI, carnival effects
- **Candidates:** Parallax Gallery, Book Flip, Masonry Grid, image-trail interactions

## 3. FLOW COMPASS — introspection / navigation / diagnosis

- **Audience:** people seeking clarity, alignment, and next steps
- **Purpose:** reflection, self-positioning, navigation
- **Core feeling:** calm, clear, insightful
- **Visual:** airy, diagrammatic, symbolic but grounded
- **Layout:** orientation -> self-check -> map/result -> guidance path -> next action
- **CTA:** guide rather than hard-sell
- **Buttons:** clear but calm; medium emphasis
- **Cards:** diagnosis cards, compass modules, quadrant blocks
- **Motion:** progressive reveal, state transitions, dial/menu interactions
- **Avoid:** visual chaos, too many simultaneous options, excessive darkness
- **Candidates:** Circle Menu, Dotted Grid, step-by-step modules

## 4. DASHBOARD / PRODUCT / QUEST BOARD — operational clarity

- **Audience:** members, learners, users, administrators
- **Purpose:** reduce friction and make the next action obvious
- **Core feeling:** efficient, clear, trustworthy
- **Visual:** product-first, low ornament, high legibility
- **Layout:** status/context -> primary next action -> supporting modules -> history/resources
- **CTA:** task completion over persuasion
- **Buttons:** compact, functional, strong hierarchy
- **Cards:** repeatable panels, status chips, progress modules
- **Motion:** state/micro-interaction only unless more adds real value
- **Avoid:** cinematic storytelling that slows repeat use
- **Candidates:** tabs, lists, progress modules, restrained hover states

## 5. INSIGHT / SOCIAL / PUBLIC-ISSUE ARTICLE — editorial clarity

- **Audience:** readers seeking understanding and orientation
- **Purpose:** communicate structure, evidence, interpretation, and implications clearly
- **Core feeling:** serious, composed, thoughtful
- **Visual:** editorial, document-like, typography-led
- **Layout:** thesis -> context -> key structure -> implications / next step
- **CTA:** reading/comprehension first; action second when relevant
- **Buttons:** minimal and secondary to content
- **Cards:** evidence blocks, quote cards, timelines, comparisons
- **Motion:** minimal
- **Avoid:** sensational graphics, confusing comparison layouts, visual pressure
- **Candidates:** text-led sections, timelines, comparison modules

## 6. KIDS / FAMILY / EDUCATION ENTRY

- **Audience:** children, parents, beginners
- **Purpose:** approachability, safety, participation
- **Core feeling:** open, encouraging, understandable
- **Visual:** brighter, friendlier, more forgiving
- **Layout:** welcome -> what it is -> why it helps -> easy next step
- **CTA:** reduce friction and invite participation
- **Buttons:** softer geometry permitted; clarity over prestige
- **Cards:** friendly modules, icons, visual cues
- **Motion:** playful but simple
- **Avoid:** intimidating luxury tone, dense philosophy at the top, over-dense copy
- **Candidates:** simple cards, visual steps, gentle reveal

## Button quick map

- **ACE style:** authority, flagship, premium, philosophy-heavy
- **Warm style:** Book Cafe, gift, family, kids, community onboarding
- **Functional style:** dashboard, forms, settings, task completion

## Promotion rule

A concept pattern becomes part of the reusable ACE UI Library only after:

1. reference shortlisting
2. `/ui-lab` experiment
3. review against Design Decision OS
4. desktop + mobile proof
5. accessibility / motion sanity check
6. reuse value confirmed
